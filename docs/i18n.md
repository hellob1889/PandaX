# i18n 国际化（Internationalization）

PandaX 自 v0.7.0 起原生支持多语言（zh-CN / en）。本指南说明翻译系统的设计原则、如何添加新语言、如何贡献翻译。
PandaX has natively supported multiple languages since v0.7.0 (zh-CN / en). This guide explains the design principles of the translation system, how to add new languages, and how to contribute translations.

## 1. 设计原则 / Design Principles

### 第一性原理 / First Principles

- **零依赖**：不引入 gettext / babel，使用内置 `dict` 数据结构
  **Zero dependencies**: no gettext / babel, uses built-in `dict` data structure
- **3 层优先级**：CLI `--lang` > 用户偏好 `~/.pandax/config.json` > OS 自动检测
  **3-layer priority**: CLI `--lang` > user preference `~/.pandax/config.json` > OS auto-detection
- **静态字符串双语**：右键菜单注册表 / `.desktop` 文件是系统级静态条目，无法动态切换，因此采用"中文 + 英文并列显示"
  **Static string bilingual**: context menu registry / `.desktop` files are system-level static entries that can't be dynamically switched, so we use "Chinese + English side-by-side display"
- **保留 README 原文**：README.md 是项目核心文档，不参与翻译（保持单一真实来源）
  **Keep README original**: README.md is the project's core document and does not participate in translation (maintain single source of truth)

### 对抗式审查 / Adversarial Review

| 攻击 / Attack | 缓解 / Mitigation |
|---|---|
| 恶意 .mo 文件注入 / Malicious .mo file injection | 翻译内置于 `pandax/i18n.py` 的 Python dict，不读外部文件 / Translations built into `pandax/i18n.py`'s Python dict, no external file reads |
| 修改 `~/.pandax/config.json` | 仅影响显示语言，不影响安全逻辑 / Only affects display language, not security logic |
| 伪造 locale 环境变量 / Fake locale env var | 严格白名单（仅 zh-CN / en）/ Strict whitelist (only zh-CN / en) |
| 翻译 key 缺失导致崩溃 / Missing translation key causes crash | `t()` 函数有 3 级 fallback（当前语言 → en → 原 key）/ `t()` function has 3-level fallback (current lang → en → original key) |

## 2. CLI 使用 / CLI Usage

```bash
# 自动检测 OS 语言（推荐）

# 右键菜单安装时指定语言（影响 PowerShell 脚本 UI）

# 查看当前生效语言

```

## 5. 占位符 / Placeholders

使用 Python `str.format()` 占位符：
Use Python `str.format()` placeholders:

```python
"ok_locked_n": "[OK] 锁定 {n} 个文件（受保护扩展名: {exts}）"
# 调用 / Call: t("ok_locked_n", n=3, exts=".py,.json")
```

占位符必须使用以下命名（保持一致）：
Placeholders must use the following naming (stay consistent):

- `{n}` / `{m}` — 数字（count / max）/ numbers (count / max)
- `{path}` / `{file}` / `{dir}` / `{root}` — 文件路径 / file paths
- `{fp}` / `{stored}` / `{current}` — 指纹哈希（截断到 16 字符）/ fingerprint hashes (truncated to 16 chars)
- `{err}` / `{e}` — 错误消息 / error messages
- `{pid}` — 进程 ID / process ID
- `{cmd}` / `{path}` — 命令字符串 / command strings
- `{base}` / `{head}` — git ref
- `{exts}` / `{text_exts}` / `{binary_exts}` — 扩展名列表 / extension lists

## 7. CI 自动审查（推荐）/ CI Auto-Review (Recommended)

项目自带对抗式审查脚本，确保每次 PR 不会引入**未翻译的中文字符串**或**翻译覆盖率倒退**。
The project ships with an adversarial review script ensuring every PR doesn't introduce **untranslated Chinese strings** or **translation coverage regression**.

```bash
# 本地先跑一遍（CI 跑之前）
# Run locally first (before CI)
python scripts/audit_i18n.py           # 人类可读 / human-readable
python scripts/audit_i18n.py --json    # CI 模式（返回 0 / 1）/ CI mode (returns 0 / 1)
python scripts/audit_i18n.py --skip-coverage   # 只检查硬编码，不查覆盖率 / only check hardcoding, not coverage
```

**审查项 / Review items**：
- ✅ 184 个 i18n keys 全覆盖（zh-CN + en）/ 184 i18n keys full coverage
- ✅ 0 处硬编码中文字符串（除 i18n.py / audit_i18n.py / 测试用例白名单）/ 0 hardcoded Chinese strings (except whitelist)
- ✅ 自动 word-boundary 排除误判（`'t(' in line` 不会被误判为 t() 调用）/ auto word-boundary exclusion

**CI 集成 / CI Integration**：`.github/workflows/lint.yml` 自动跑该脚本，任何 PR 引入硬编码中文或翻译缺失 → CI 失败。
`.github/workflows/lint.yml` auto-runs this script; any PR introducing hardcoded Chinese or missing translation → CI fails.

## 10. 排错 / Troubleshooting

### Q: 改了 `~/.pandax/config.json` 不生效？/ Modified `~/.pandax/config.json` but no effect?

A: 检查文件编码（必须是 UTF-8 无 BOM），JSON 格式（`{"lang": "en"}`）。删除文件重新运行 `pandax --lang=en` 会自动重新写入。
Check file encoding (must be UTF-8 without BOM), JSON format (`{"lang": "en"}`). Delete the file and re-run `pandax --lang=en` to auto-rewrite it.

### Q: 中文 Windows 系统显示英文？/ Chinese Windows shows English?

A: 优先级 `--lang` > 偏好 > 自动检测。如果手动跑过 `pandax --lang=en`，会持久化偏好。删除 `~/.pandax/config.json` 重置自动检测。
Priority: `--lang` > preference > auto-detection. If you manually ran `pandax --lang=en`, preference is persisted. Delete `~/.pandax/config.json` to reset auto-detection.

### Q: 添加了翻译但显示 fallback？/ Added translation but shows fallback?

A: 检查 key 拼写（Python dict 区分大小写）。运行 `coverage_report()` 看 missing 列表。
Check key spelling (Python dict is case-sensitive). Run `coverage_report()` to see missing list.

## 11. `install-context --lang`：右键菜单跨平台 i18n / Cross-Platform Context Menu i18n

`pandax install-context --lang=en` 不只是改 CLI 偏好，它会让所有平台的右键安装脚本**用对应语言写出的 UI 文案**。
`pandax install-context --lang=en` doesn't just change CLI preference; it makes all platform context menu install scripts **write UI text in the corresponding language**.

### 平台差异（按"第一性原理"）/ Platform Differences (First-Principles View)

| 平台 / Platform | 右键菜单机制 / Context Menu Mechanism | i18n 实现 / i18n Implementation |
|---|---|---|
| **Windows** | 注册表 `HKCU\Software\Classes\*\shell\Pandax` / Registry | PS1 脚本读 `TXT_*` 变量 / PS1 script reads `TXT_*` vars |
| **macOS** | `~/Library/Services/*.workflow` (Automator Quick Action) | `.wflow` 模板 `{TXT_XXX}` 占位符 + Python 渲染 / template placeholder + Python rendering |
| **Linux (Nautilus)** | `~/.local/share/nautilus/scripts/PandaX` | Python 脚本内嵌 `T = {"zh-CN":..., "en":...}` dict / Python script embeds dict |
| **Linux (Dolphin)** | `~/.local/share/kservices5/ServiceMenus/pandax-lock.desktop` | `Name[zh_CN]=...` `Name[en]=...` 双 locale 字段 / dual locale fields |
| **Linux (Nautilus)** | 同上（Python 脚本）/ Same (Python script) | 同上 / Same |

### 语言解析优先级（所有安装脚本一致）/ Language Resolution Priority (Consistent Across Install Scripts)

```
1. 环境变量 PANDAX_LANG           （pandax CLI 显式传 / explicitly passed by pandax CLI）
2. ~/.pandax/config.json           （pandax --lang 写过的偏好 / preference written by pandax --lang）
3. 默认 zh-CN / Default zh-CN
```

### 用法 / Usage

```bash
# CLI 调用：安装 + 自动传 PANDAX_LANG
# CLI call: install + auto-pass PANDAX_LANG
pandax install-context --lang=en    # 安装英文右键菜单 / install English context menu
pandax install-context              # 用 ~/.pandax/config.json 的语言 / use ~/.pandax/config.json language

# 手动调用：环境变量
# Manual call: env var
PANDAX_LANG=en bash installer/linux/install_context_menu.sh
PANDAX_LANG=en bash installer/macos/install_context_menu.sh

# 完全离线 / config.json 缺失：默认中文
# Fully offline / config.json missing: default Chinese
bash installer/linux/install_context_menu.sh   # 中文 UI / Chinese UI
```

### 限制 / Limitations

- **macOS .workflow 内的 AppleScript** (`document.wflow` COMMAND_STRING) 由 i18n 渲染，但 Finder 的 Quick Action 菜单标题取自 `Info.plist`（已含 `CFBundleName = PandaX Lock`，对所有语言显示相同）/ i18n-rendered, but Quick Action menu title from `Info.plist` (same for all languages)
- **Linux Dolphin .desktop 菜单标题** 通过 `Name[zh_CN]` / `Name[en]` 多 locale 字段实现，无需切换 / Multi-locale fields, no switching needed
- **Nautilus "Scripts" 子菜单**：名称取自 `~/.local/share/nautilus/scripts/PandaX` 文件名（"PandaX"，不变）/ Name from filename (immutable)
