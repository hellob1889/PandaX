# i18n 国际化（Internationalization）

PandaX 自 v0.7.0 起原生支持多语言（zh-CN / en）。本指南说明翻译系统的设计原则、如何添加新语言、如何贡献翻译。

## 1. 设计原则

### 第一性原理

- **零依赖**：不引入 gettext / babel，使用内置 `dict` 数据结构
- **3 层优先级**：CLI `--lang` > 用户偏好 `~/.pandax/config.json` > OS 自动检测
- **静态字符串双语**：右键菜单注册表 / `.desktop` 文件是系统级静态条目，无法动态切换，因此采用"中文 + 英文并列显示"
- **保留 README 原文**：README.md 是项目核心文档，不参与翻译（保持单一真实来源）

### 对抗式审查

| 攻击 | 缓解 |
|---|---|
| 恶意 .mo 文件注入 | 翻译内置于 `pandax/i18n.py` 的 Python dict，不读外部文件 |
| 修改 `~/.pandax/config.json` | 仅影响显示语言，不影响安全逻辑 |
| 伪造 locale 环境变量 | 严格白名单（仅 zh-CN / en） |
| 翻译 key 缺失导致崩溃 | `t()` 函数有 3 级 fallback（当前语言 → en → 原 key） |

## 2. CLI 使用

```bash
# 自动检测 OS 语言（推荐）
pandax                      # 中文系统 → 中文；其他 → 英文

# 显式指定语言（覆盖自动检测）
pandax --lang=zh-CN         # 强制中文
pandax --lang=en            # 强制英文

# 右键菜单安装时指定语言（影响 PowerShell 脚本 UI）
pandax install-context --lang=en

# 查看当前生效语言
python -c "from pandax import i18n; print(i18n.get_lang())"
```

## 3. 添加新语言

### Step 1：在 `TRANSLATIONS` 里加新条目

编辑 `src/pandax/i18n.py`，在 `TRANSLATIONS` 字典中新增一个键：

```python
TRANSLATIONS = {
    "zh-CN": {...},  # 已存在
    "en": {...},     # 已存在
    "ja": {          # NEW: 日本語
        "_lang_name": "日本語",
        # ... 复制 zh-CN 的所有 key，逐一翻译
        "ok_locked_n": "{n} 個のファイルをロックしました...",
        ...
    },
}
```

### Step 2：检查覆盖率

```python
from pandax import i18n
report = i18n.coverage_report()
print(report["ja"])
# {'total': 149, 'present': 149, 'missing': [], 'missing_pct': 0.0}
```

### Step 3：扩展 CLI `--lang` 选项

编辑 `src/pandax/cli.py` 的 `build_parser`：

```python
parser.add_argument("--lang", choices=["zh-CN", "en", "ja"], default=None, ...)
```

### Step 4：扩展自动检测（可选）

编辑 `src/pandax/i18n.py` 的 `_detect_os_language()`：

```python
if lang_lower.startswith("ja"):
    return "ja"
```

### Step 5：测试

```bash
pandax --lang=ja status
```

## 4. 翻译 key 命名规范

| 前缀 | 含义 | 示例 |
|---|---|---|
| `ok_*` | 成功消息 | `ok_locked_n`, `ok_written` |
| `err_*` | 错误消息 | `err_fingerprint_mismatch` |
| `warn_*` | 警告消息 | `warn_lock_failed` |
| `info_*` | 信息消息 | `info_fp_generated`, `info_os_detected` |
| `status_*` | `pandax status` 输出 | `status_l1`, `status_total` |
| `write_reject_*` | `pandax write` 拒绝原因 | `write_reject_target_not_exist` |
| `log_*` | `pandax log` 输出 | `log_header`, `log_field_*` |
| `git_*` | `pandax install-git` | `git_probe_found` |
| `hook_*` | `pandax install-hook` | `hook_installed` |
| `watch_*` | `pandax watch` | `watch_daemon_started` |
| `ci_*` | `pandax ci` | `ci_pass_all`, `ci_fail_n` |
| `menu_*` | 右键菜单静态 | `menu_init`, `menu_lock` |
| `macos_*` | macOS workflow 弹窗 | `macos_choose_prompt` |
| `_*` | 内部 helper（也需翻译） | `_stored`, `_current` |

## 5. 占位符

使用 Python `str.format()` 占位符：

```python
"ok_locked_n": "[OK] 锁定 {n} 个文件（受保护扩展名: {exts}）"
# 调用：t("ok_locked_n", n=3, exts=".py,.json")
```

占位符必须使用以下命名（保持一致）：

- `{n}` / `{m}` — 数字（count / max）
- `{path}` / `{file}` / `{dir}` / `{root}` — 文件路径
- `{fp}` / `{stored}` / `{current}` — 指纹哈希（截断到 16 字符）
- `{err}` / `{e}` — 错误消息
- `{pid}` — 进程 ID
- `{cmd}` / `{path}` — 命令字符串
- `{base}` / `{head}` — git ref
- `{exts}` / `{text_exts}` / `{binary_exts}` — 扩展名列表

## 6. 贡献翻译

1. Fork 仓库
2. 编辑 `src/pandax/i18n.py`
3. 跑测试：`python -m pytest tests/test_i18n.py -v`
4. 跑覆盖率：`python -c "from pandax import i18n; print(i18n.coverage_report())"`
5. 提交 PR，标题格式：`i18n: add XX translation (xx)`（例如 `i18n: add Japanese translation (ja)`）

## 7. CI 自动审查（推荐）

项目自带对抗式审查脚本，确保每次 PR 不会引入**未翻译的中文字符串**或**翻译覆盖率倒退**。

```bash
# 本地先跑一遍（CI 跑之前）
python scripts/audit_i18n.py           # 人类可读
python scripts/audit_i18n.py --json    # CI 模式（返回 0 / 1）
python scripts/audit_i18n.py --skip-coverage   # 只检查硬编码，不查覆盖率
```

**审查项**：
- ✅ 184 个 i18n keys 全覆盖（zh-CN + en）
- ✅ 0 处硬编码中文字符串（除 i18n.py / audit_i18n.py / 测试用例白名单）
- ✅ 自动 word-boundary 排除误判（`'t(' in line` 不会被误判为 t() 调用）

**CI 集成**：`.github/workflows/lint.yml` 自动跑该脚本，任何 PR 引入硬编码中文或翻译缺失 → CI 失败。

## 8. 不翻译的内容

| 内容 | 原因 |
|---|---|
| README.md 步骤列表（`Step 9` 等） | 单源真相，由开发者维护 |
| 注释 / docstring | 代码可读性 |
| ASCII art banner | 视觉一致性 |
| git commit hash | 哈希值不可翻译 |
| 内部 ID（`audit_xxx`、`APPROVED` 等） | 机器可读字段 |
| 文件名 / 路径 | 系统级标识 |

## 9. 测试覆盖

`tests/test_i18n.py`（39 个测试）覆盖：

- `_detect_os_language()` 各种环境组合
- `init()` / `get_lang()` / `set_lang()` 优先级链
- `t()` 占位符 + fallback
- `coverage_report()` 准确性
- 持久化读写 `~/.pandax/config.json`

## 9. 排错

### Q: 改了 `~/.pandax/config.json` 不生效？

A: 检查文件编码（必须是 UTF-8 无 BOM），JSON 格式（`{"lang": "en"}`）。删除文件重新运行 `pandax --lang=en` 会自动重新写入。

### Q: 中文 Windows 系统显示英文？

A: 优先级 `--lang` > 偏好 > 自动检测。如果手动跑过 `pandax --lang=en`，会持久化偏好。删除 `~/.pandax/config.json` 重置自动检测。

### Q: 添加了翻译但显示 fallback？

A: 检查 key 拼写（Python dict 区分大小写）。运行 `coverage_report()` 看 missing 列表。

## 10. `install-context --lang`：右键菜单跨平台 i18n

`pandax install-context --lang=en` 不只是改 CLI 偏好，它会让所有平台的右键安装脚本**用对应语言写出的 UI 文案**。

### 平台差异（按"第一性原理"）

| 平台 | 右键菜单机制 | i18n 实现 |
|---|---|---|
| **Windows** | 注册表 `HKCU\Software\Classes\*\shell\Pandax` | PS1 脚本读 `TXT_*` 变量 |
| **macOS** | `~/Library/Services/*.workflow` (Automator Quick Action) | `.wflow` 模板 `{TXT_XXX}` 占位符 + Python 渲染 |
| **Linux (Nautilus)** | `~/.local/share/nautilus/scripts/PandaX` | Python 脚本内嵌 `T = {"zh-CN":..., "en":...}` dict |
| **Linux (Dolphin)** | `~/.local/share/kservices5/ServiceMenus/pandax-lock.desktop` | `Name[zh_CN]=...` `Name[en]=...` 双 locale 字段 |
| **Linux (Nautilus)** | 同上（Python 脚本） | 同上 |

### 语言解析优先级（所有安装脚本一致）

```
1. 环境变量 PANDAX_LANG           （pandax CLI 显式传）
2. ~/.pandax/config.json           （pandax --lang 写过的偏好）
3. 默认 zh-CN
```

### 用法

```bash
# CLI 调用：安装 + 自动传 PANDAX_LANG
pandax install-context --lang=en    # 安装英文右键菜单
pandax install-context              # 用 ~/.pandax/config.json 的语言

# 手动调用：环境变量
PANDAX_LANG=en bash installer/linux/install_context_menu.sh
PANDAX_LANG=en bash installer/macos/install_context_menu.sh

# 完全离线 / config.json 缺失：默认中文
bash installer/linux/install_context_menu.sh   # 中文 UI
```

### 改动覆盖范围（v0.7.0+）

| 文件 | 改动 |
|---|---|
| `installer/windows/install_context_menu.ps1` | 全部 UI 用 `$TXT_xxx` 变量，按 `$USER_LANG` 切换 |
| `installer/macos/install_context_menu.sh` | 同上（`$TXT_xxx`） |
| `installer/linux/install_context_menu.sh` | 同上 |
| `installer/macos/PandaX Lock.workflow/Contents/document.wflow` | 模板化 `{TXT_XXX}`，安装时 Python 渲染 |
| `installer/linux/nautilus/PandaX` | Python 脚本内嵌双语 dict `T[lang][key]` |
| `src/pandax/cli.py` `_run_installer` | 子进程 env 加 `PANDAX_LANG=get_lang()` |

### 限制

- **macOS .workflow 内的 AppleScript** (`document.wflow` COMMAND_STRING) 由 i18n 渲染，但 Finder 的 Quick Action 菜单标题取自 `Info.plist`（已含 `CFBundleName = PandaX Lock`，对所有语言显示相同）
- **Linux Dolphin .desktop 菜单标题** 通过 `Name[zh_CN]` / `Name[en]` 多 locale 字段实现，无需切换
- **Nautilus "Scripts" 子菜单**：名称取自 `~/.local/share/nautilus/scripts/PandaX` 文件名（"PandaX"，不变）
